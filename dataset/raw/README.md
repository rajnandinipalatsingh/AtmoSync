# Raw Dataset

This folder contains the original dataset provided for the AtmoSync project.

## Dataset

File:
- `Microclimate_dataset.csv`

## Important Rule

The raw dataset must never be modified directly.

All cleaning, transformation, and feature engineering should be performed through the notebooks or Python scripts.

## Dataset Description

The dataset contains microclimate observations collected from multiple monitoring locations.

The main environmental variables include:

- Temperature
- Humidity
- Wind Speed
- Solar Radiation
- Precipitation
- Air Pressure
- NDVI

The dataset also contains:

- Timestamp
- Location ID
- Latitude
- Longitude
- LULC Type
