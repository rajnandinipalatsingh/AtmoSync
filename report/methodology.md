# Methodology

## 1. Data Collection

The project uses the supplied microclimate dataset.

## 2. Data Cleaning

The dataset was inspected for:

- Missing values
- Duplicate records
- Invalid data types
- Invalid environmental values

## 3. Feature Engineering

Additional analytical variables were created:

- Hour
- Minute
- Time Period
- Temperature Anomaly
- Dew Point
- NDVI Category
- Solar Radiation Band

## 4. Exploratory Data Analysis

EDA was performed to understand:

- Environmental distributions
- Temporal patterns
- LULC differences
- Location differences
- Correlations

## 5. Analytical Interpretation

The final analysis converts statistical results into environmental insights.
